# Ақ Отау RestoBar — меню

Страница из фотографий меню. Никакой вёрстки: восемь фотографий меню
подряд, каждая во всю ширину экрана, в том же порядке, в котором вы их прислали.

## Структура

```
restaurant-qr-menu/
├── index.html      ← 8 картинок подряд, больше ничего
├── styles.css      ← 3 правила: фото во всю ширину + кнопка «наверх»
├── script.js       ← только кнопка «наверх»
├── images/         ← фотографии меню (01-cover.jpg … 08-drinks.jpg)
├── restaurant-qr-menu.zip
└── README.md
```

## Как запустить

Откройте `index.html` двойным кликом.

Для публикации (GitHub Pages / Netlify / Vercel / любой статик-хостинг) залейте
папку целиком. Для QR-кода по локальной сети:

```bash
python -m http.server 8080
```

и откройте `http://<IP-компьютера>:8080` с телефона в той же Wi-Fi сети.

## Как поменять фото

Положите файлы в `images/` с теми же именами (`01-cover.jpg` … `08-drinks.jpg`).
Подробности в `images/README.txt`.

## Что можно настроить

- **Ограничить ширину фото** (чтобы не мылось на широких мониторах) — в `styles.css`:

  ```css
  img { max-width: 2200px; margin: 0 auto; }
  ```

- **Добавить или убрать страницу** — просто скопируйте/удалите строку
  `<img src="images/..." alt="...">` в `index.html`.

- **Убрать кнопку «наверх»** — удалите `<button class="to-top" id="toTop">`
  и подключение скрипта из `index.html`.

- **Печать** — Ctrl+P → PDF: каждое фото на отдельном листе.
