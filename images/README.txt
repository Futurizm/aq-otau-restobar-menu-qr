Как заменить фото
-----------------
Просто положите свои файлы с этими именами в папку images/ и обновите
страницу. Порядок на сайте = порядок файлов (01, 02, 03...).

Фото показываются во всю ширину экрана, в натуральных пропорциях.
Рекомендуемый размер: 1600 px по ширине и выше (сейчас ровно 1600 x 1131).
Чтобы фото не мылилось на очень широких мониторах, можно в styles.css
добавить ограничение ширины:

    img { max-width: 2200px; margin: 0 auto; }

Как добавить/удалить страницу меню
----------------------------------
Откройте index.html — там 8 обычных картинок подряд, без обвязки:

    <img src="images/09-new-page.jpg" alt="Раздел меню">

Скопируйте такую строку и вставьте в нужное место.
